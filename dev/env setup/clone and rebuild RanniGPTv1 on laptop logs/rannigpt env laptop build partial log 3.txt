So this time we do things in this order:
- Install build tools and git clone tts repo
- Install conda-only part, with pip==24.0 (conda env create -f)
- ACTIVATE ENV !
- Install pip-only part, WITHOUT tts package in the requirements (we want editable version)
- cd TTS -> Backup original TTS requirements txt -> drag in modified requirements and rename
- Install editable version of tts package
